# 社内管理システム

従業員の登録・一覧・編集と、初期パスワードの通知、初回ログイン時のパスワード変更、パスワード再設定を行う社内向けの画面です。表示言語は日本語です。

この範囲に含まれるのは次だけです。

- 従業員の登録、一覧、編集（所属、メールアドレス、氏名、会社が自社か他社か）
- 登録時に初期パスワードをメールで送る
- 初回ログイン後、他の画面へ進む前のパスワード変更
- 1回だけ使えるパスワード再設定URL

従業員の削除、画面からの権限変更、その他の業務機能は含みません。

## 必要なもの

- Node.js 22 以上
- Docker（PostgreSQL 16 を起動するため）

Docker を使わない場合は、自分で PostgreSQL 16 を用意し、下の `DATABASE_URL` に合わせてください。

## 起動手順

```bash
docker compose up -d
npm install
npm run db:setup
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

`npm run db:setup` は、まだ `.env.local` が無いときに `.env.example` から作成し、`AUTH_SECRET` をランダムな値にします。

## データベース

`docker compose` は次の接続先を作ります。

```text
postgres://ies:ies@localhost:5432/ies
```

`npm run db:setup` はテーブルを作成し、管理者がいないときだけ初期管理者を1件追加します。既存のデータは消しません。

データを消して最初から作り直す場合:

```bash
npm run db:reset
```

パスワードは bcrypt で保存します。再設定トークンは SHA-256 のハッシュだけを保存し、有効期限を持ちます。

## 初期管理者

| 項目 | 値 |
| --- | --- |
| メールアドレス（ログインID） | `admin@example.com` |
| 初期パスワード | `Admin1234!` |
| 氏名 | 管理者 |
| 所属 | 管理 |
| 会社 | 自社 |

初回ログイン後は、パスワードを変更するまで従業員管理へ進めません。ログアウト以外ではこの画面をスキップできません。

同じメールアドレスの管理者が既にいる場合、パスワードは上書きしません。初期のパスワードに戻すには `npm run db:reset` を実行してください。

`SEED_ADMIN_EMAIL` と `SEED_ADMIN_PASSWORD` で初期値を変更できます。パスワードは8文字以上72文字以内で、英字と数字を含める必要があります。

## 開発用メールの確認

開発時は SMTP を設定しません。送信されたメールはデータベースの `dev_mailbox` に保存されます。

開発サーバーで次のURLを開くと、宛先、件名、本文を確認できます。ログイン画面の「開発用メールを確認」からも開けます。

http://localhost:3000/dev/emails

初期パスワードと再設定URLは、この受信箱（または本番のSMTP）にだけ出します。アプリのログには宛先と件名だけを出し、本文は出しません。Next.js の Server Function 引数ログも無効にしてあります。再設定URLへのアクセスログも出しません。

この画面は `next dev` のときだけ表示されます。`next start` では 404 になります。開発サーバーに届く人はメール本文を読めます。

## 本番のメール送信

SMTP を使うときは、次の環境変数を設定します。未設定の本番環境では、初期パスワードを渡せないため従業員登録は失敗し、登録内容は残りません。

```text
SMTP_HOST
SMTP_PORT
SMTP_SECURE
SMTP_USER
SMTP_PASSWORD
SMTP_FROM
```

例は `.env.example` にあります。`SMTP_PORT` の既定は 587 です。`SMTP_SECURE=true` またはポート 465 のときは TLS で接続します。

## パスワード再設定

ログイン画面の「パスワードを忘れた方」から再設定メールを送ります。メールのURLは1回だけ使え、有効期限は既定で60分です。期限切れ、使用済み、無効なリンクは、それぞれ別のメッセージで失敗します。

`RESET_TOKEN_TTL_MINUTES` で有効期限（分）を変更できます。

## スクリプト

- `npm run dev` — 開発サーバー
- `npm run build` / `npm run start` — 本番起動
- `npm run db:setup` — スキーマ作成と初期管理者
- `npm run db:reset` — データを消して作り直し
- `npm run typecheck` — 型チェック
- `npm run verify` — 登録、初期パスワード、初回変更、再設定リンクの確認
